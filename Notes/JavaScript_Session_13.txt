->DOM:
======
             JavaScript supports DOM which stands document object model.The main objective
of DOM is how to make Dynamic Web pages as per the application reqn.

D --->Document ---->It can be any document

O ---->Object    ----> All HTML/HTML5 tags act as Object in JavaScript

M --->Model   ------> How to represent Dynamic Content on web page


DOM provides following methods which are as follows
======================================
->document.write()
->document.writeln()
->document.getElementById()
->document.getElementsByName()
->document.getElementsByTagName()
->document.getElementsByClassName()


->document.getElementById():
======================
                                                 It is method which is present inside the DOM.The main objective of this method is read the data/information from the text_field  and perform
the operations as per the application reqn.


Ex1:
===
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

Working on innerHTML:
=================
                             The main objective of innerHTML is to display the dynamic message on
the web page as per the application reqn.innerHTML is assoicated with document.getElementId().


Ex1:
===
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JavaScript_Session</title>
</head>
<body>
    <hr>
    <center><h1><tt>Employee Login</tt></h1></center>
    <hr>
    <hr>
    <fieldset>
        <legend>Login_Form</legend>
        <center>
            <form action="" method="post" onsubmit="return Test_Case1()">
            <table border="3">
              <tr>
                <td><label for="">Username</label></td>
                <td><input type="text" placeholder="Username" id="A" autocomplete="off"></td>
                <td><span id="ABC"></span></td>
              </tr>
                  <tr>
                <td><label for="">Password</label></td>
                <td><input type="password" placeholder="Password" id="B" autocomplete="off"></td>
                <td><span id="abc"></span></td>
              </tr>
              <tr>
                <td></td>
                <td>
                    <input type="submit" value="LOGIN">
                    <input type="reset" value="RESET">
                </td>
              </tr>
                
            </table>
            </form>
        </center>
    </fieldset>
    <hr>
    <script>
        function Test_Case1()
        {
           var username=document.getElementById("A").value 
           var p1=document.getElementById("B").value
           if(username==""||username==null)
           {
            window.alert("Dear Employee:Username is required")
            document.getElementById("ABC").innerHTML="*** Dear Employee:Username is required  ***"
            return false

           }
           else if(p1==""||p1==null)
           {
            window.alert("Dear Employee:Password is required")
            document.getElementById("abc").innerHTML="*** Dear Employee:Password is required ***"
            return false
           }
          
        }
    </script>
   
    
    
</body>
</html>
