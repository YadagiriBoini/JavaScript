->****Rest Parameter ****:
==================
                           JavaScript supports Rest Parameter.We can define or declare
...followed by variable_name.The main objective of rest_parameter to read zero or more then one number of arguments and perform the operations as 
per the application reqn.


Ex1:
===

type of variables are there 

->global variable
->local variable

->global variable:
============
                               global variable can be define or declare in JavaScript using 
var keyword followed by variable_name.The scope of the global variable we
can access any_where.


Ex1:
===

        function T1()
         {
            for(var a=0;a<ages.length;a++)

             }
         }

=========
               In JavaScript local variable can be define or declare inside the function using let keyword followed variable_name.The scope of the local
variable with_in function not outsite the function.


Ex1:
===
