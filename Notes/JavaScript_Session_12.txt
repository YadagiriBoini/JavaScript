->Events in JavaScript:
===============
                    JavaScript supports Events.The main objeective of events is perform an action
as per the application reqn.

->onclick()
->onsubmit()


->onclick():
=======
              onclick() is a JavaScript events meant for button validation.

===
<!DOCTYPE html>

<head>

    <hr>
    <center>
    <h1><tt>JavaSript_Session</tt></h1>

            {
                window.alert('Welcome to Events in JavaScript')
            }

Working on Date object:
=================
                         JavaScript supports Date object.The main objective of date object is to work on IST TIME.We can create date obejct in JavaScript as follows

var d1  = new Date() ---->IST TIME


getFullYear():It is used to display current year in number format  ----> 1970
getFullDay(): it is used to display the day in number format  ---> 0 to 7
getMonth():It is used to display the month in number format 
getHours():It is used to dispaly the hours in 24 hours format  ----> 0 to 23
getMinutes():It is used to display the minutes in number format from 0 to 59 
getSeconds():It is used to display the seconds in number format from 0 to 59
