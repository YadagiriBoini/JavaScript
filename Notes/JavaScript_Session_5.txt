->Bitwise left_shift operator(<<):
======================
X1=20 
X2=X1<<2


20  ---->  1  0    1   0   0 
                    apply the 2 0's left_side

                       0    0    1    0    1    0    0 
 
                                     1   0   1   0   0   0   0

->Bitwise right_shift operator(>>):
=======================

X1=20 
X2=X1>>2 

20  -----> 1  0   1   0   0  

                   apply 2 0's left_side 

                        0    0    1   0    1   0   0

                             0    0    0   0   1    0   1

Nested if statement:
=============
                    JavaScript supports nested if statement.It is also known as inner 
if statement.Nested if statement or Inner if statement can represent as if 
we are defining or declaring a if statement inside another if statement then
it said to be Nested if statement.

if(condition)
    {
         ----
        if(condition)
           {
                ----
           }
   }

====================

if-else if -else:
==========
                  JavaScript supports if-else if-else.The main objective of if-elseif else is to check more then one condition as per the application reqn.Following is the syntax for if-else if-else 

if(condition) 
{
   ---
}
else if(condition)
{
  ---
}
else if(condition)
 {
  --
}
else 
{
 ---
}

want to execute number of statements number of time if our data is in

in JavaScript

     ---
  }
