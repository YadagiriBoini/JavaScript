Control statement in JavaScript:
======================
JavaScript supports Following types of control statement which are as follows

->if statement 
->nested if statement
->if-else statement 
->if-else if-else statement
->for loop
->nested for loop
->for in loop
->forEach loop
->while loop
->do while loop
->nested while loop
->break 
->continue statement
->switch statement


->if statement:
==========
JavaScript supports if statement.If 'if' block condition is satisfied then if block will be
executed.Following is the syntax for if statement.

if(condition)
{
---
}

->nested if statement:
================
JavaScript supports nested if statement.It is also known as inner if statement.Nested if statement/Inner if statement can be define or declare if statement inside the another 
if statement then it is said to nested if statement.

if(condition)
{
    if(condition)
       {
         ---
       }
}

if-else:
=====
         JavaScript supports if-else statement.If 'if' condition is satisfied then if block will be
executed otherwise else block will be executed.Following is the syntax for if-else statement

if(condition)
{
 ---
}
else 
{
---
}

if-else if -else:
=========
                 JavaScript supports if-else if-else.The main objective of if-else if else is to check the more then one condition.

if(condition)
{
  ---
}
else if(condition)
{
  ---
}
else if(condition)
{
---
}
