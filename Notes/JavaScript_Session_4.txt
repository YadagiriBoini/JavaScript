->An Object data type:
===============
JavaScript supports An object data type.An object data can be represent as name/values pair.In JavaScript we can define or declare an object data type using following ways

->Using an object literal
->Using an Instance of an object
->Using an Object based constructor


->Using an object literal:
=================

Ex1:
===
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JavaScript_Session</title>
</head>
<body>
    <hr>
    <center>
    <h1><tt>JavaScript_Session</tt></h1>
    </center>
    <hr>
    <script>
        var Product_Information={
            "Pid":1001,
            "Pname":"Mobile_1",
            "Price":29000.0,
            "Company":"Samsung",
        }
        document.write("Pid is:"+Product_Information.Pid)
        document.write("<hr>")
        document.write("Pname is:"+Product_Information.Pname)
        document.write("<hr>")
        document.write("Price is:"+Product_Information.Price)
        document.write("<hr>")
        document.write("Company is:"+Product_Information.Company)
    </script>
    
</body>
</html>

An operators in JavaScript:
==================
JavaScript supports an operator.An operator is symbol which is used to perform the 
operations as per the application reqn.In JavaScript We do have following types of 
opeators which are as follows

->Arithmetic operators
->Assignment operators
->Logical operators
->Comparision operators
->Bitwise operators
->Ternary operator

->Logical operators:
==============
JavaScript supports Logical operators.The main objective of logical operators is to perform 
logical operations in the application development.Following are the Logical operators in JavaScript


->Logical and   ---->  && 
->Logical or     -----> ||
->Logical not    -----> !
