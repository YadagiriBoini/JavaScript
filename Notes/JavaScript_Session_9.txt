for loop in JavaScript:
===============
JavaScript supports for loop.The main objective of for loop in JavaScript if you want to execute number of statement number of time if our data is in sequence then we can go 
with for loop.

Nested for loop:
===========
                JavaScript supports Nested for loop.It is also known as Inner for loop.Nested for 
loop/Inner for loop can be represent as defining or declaring a for loop inide another for loop then it is said to be Nested for loop.Following is the syntax

for(condition)
{
    for(condition)
     {
         ---
     }
}

->while loop:
=========
               JavaScript supports while loop.If you want to execute number  of statement number of times if our data/information not in sequence or infinite loop.Following is
syntax for while loop in JavaScript

a1=0 
while(condition)
{
      ---
      a1++
}
