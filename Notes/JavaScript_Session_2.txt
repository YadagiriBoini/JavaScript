Typecasting in JavaScript:
=================
                                   JavaScript supports Typecasting.It is the process or methodlogy to convert from one data type into another data type using
following predefine functions

->parseInt()
->parseFloat()
->Number()

Ex1:
===
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>JavaScript_Session</title>
</head>
<body>
    <hr>
    <center>
        <h1><tt>JavaScript_Session</tt></h1>
    </center>
    <hr>
    <script>
        var a =parseInt(window.prompt("Enter the value of a:"))
        var b=parseInt(window.prompt("Enter the value of b:"))
        var c=a+b 
        document.write(a+" "+typeof(a))
        document.write("<hr>")
        document.write(b+" "+typeof(b))
        document.write("<hr>")
        document.write(c+" "+typeof(c))
    </script>
    
</body>
</html>

->push():
======

push() function/method is to add one or more then one elemements
inside the an array.
