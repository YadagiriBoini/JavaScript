->Regex Object data type(Regular Expression):
===============================
                                        JavaScript supports Regex Object data type.It is also 
known as regular expression.The main objective of regex object(Regular expression) if you want represent a string as a pattern what we are searching
then we can go with regex object data type(Regular expression).


->match()
->search()

->match():
=======
              It is a predefine function in JavaScript.The main objective of match() is to match and return pattern as per the application reqn.


->search():
=======
             It is a predefine function in JavaScript.The main objective of search()
function is return the indexing position of the pattern where our pattern starts if pattern not found return -1

//i -- g

i means case sentitive and case in_sensitive as well only once pattern

g means only case sensitive for more then one pattern

Character classes in JavaScript:
=====================
[ABC]  --->A,B,C 
[a-z]   ---->All lowercase characters from a to z 
[A-Z]   ---->All uppercase characters from A to Z 
[0-9]  -----> Digit from 0 to 9
[a-zA-Z]  ----> All uppercase and lowercase characters
[a-zA-Z0-9]  ---->Alpha numerical values 
[^a-zA-Z0-9]  ---> Only specail characters

Quantifiers in JavaScript:
================
A ---->  Only A's 
A+  ----> Minimum one A or more then one A's
A*  ----> Minimum one A or more then one A's with Zero number of A's and
end+1
A?  ---->Only Single A's and zero number of A's and end+1 
A{2,4} --->AA,AAA,AAAA  are allowed

^A  ---->  Wheather our pattern starts with A or not 
A$  ---->  Wheather our pattern ends with or A or not
